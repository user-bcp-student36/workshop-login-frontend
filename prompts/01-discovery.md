# Prompt 01 — Discovery

Actúa como arquitecto frontend senior. Analiza este repositorio Angular sin modificar archivos. Entrega:

1. mapa de componentes, dependencias y flujo de autenticación;
2. code smells ordenados por impacto;
3. riesgos de seguridad del navegador;
4. dependencias vulnerables y estrategia de remediación;
5. plan de refactorización en PRs pequeños, preservando comportamiento.

No inventes resultados de herramientas. Distingue hallazgos confirmados de hipótesis.
